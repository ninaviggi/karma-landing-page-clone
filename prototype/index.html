Naming Things · Prototype v0.1

A bilingual activity guide for parents learning alongside their child.

Static mockup of the mobile screens. Open any screen below — they link to each other.

01 Onboarding First launch. Set learning language, child's age, optional name. 02 Home "What are we doing?" — text input and activity suggestions. 03 Activity card Generated bilingual guide: vocab, sentences, steps, wonder question. 04 Vocabulary bank Persistent library of every word and sentence learned, tagged by activity. 05 Progress Quiet stats — no badges, no streaks. Just growth.

This is a static HTML mockup using the production design tokens (warm off-white, sand surfaces, deep forest accent). The real app is in naming-things/ — React Native + Expo, with Claude-generated activities and SQLite-backed vocab. Audio buttons here are visual only; in the real app they speak the word via platform TTS.
